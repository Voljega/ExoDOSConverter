If you want to build your own executable on Windows, it's pretty straightforward :
- Install your Python 3.8 or 3.9 environment
- Launch python prompt
- Install pyinstaller with this command : `pip install pyinstaller`
- Install the libraries the tool needs with `pip install -r requirements.txt` (pillow, requests, chardet and ttkbootstrap)
- Get latest commits through git (git pull)
- Now you can EITHER launch build.bat (simple way, the version number comes from `version.py`, bump it before building a release) or do the following :
- Copy all `.py` files and the `exodosicon.ico` file in a work directory
- Go into the work directory and type : `pyinstaller --icon=exodosicon.ico --clean --collect-all ttkbootstrap -F main.py`
- Your exe will be generated into a `dist` subDirectory
- Just copy README.md, exodosicon.ico, build.txt and data and GUI directories alongside the main exe, and create an empty conf directory (the configuration files are created by the tool), and you're good to go
- Delete cache and data/mister/distro subfolder in your dist dir if it exists
